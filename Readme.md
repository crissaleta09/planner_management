Proyecto destinado para la gestión y control de agenda social
Este proyecto tiene como objetivo proporcionar una herramienta eficiente para la gestión y control de la agenda social de los usuarios. A través de esta aplicación, los usuarios podrán organizar sus eventos, citas y recordatorios de manera sencilla y efectiva.
## Características principales
- **Gestión de usuarios:** Permite crear, editar, eliminar y visualizar usuarios.
- **Control de agenda:** Los usuarios pueden agregar, modificar y eliminar eventos en su agenda.
- **Recordatorios:** Funcionalidad para establecer recordatorios para eventos importantes.
## Tecnologías utilizadas
- **Frontend:** HTML, CSS, JavaScript, React.js
- **Backend:** JAVA, Spring Boot, Maven.
- **Base de datos:** MySQL
- **Control de versiones:** Git y GitHub
